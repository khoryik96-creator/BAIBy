The Unity game is built by GitHub Actions and isn't stored in git. Download a build into build/Web from the Codespace terminal, then reload this page:

gh run download RUN_ID --name baiby-web --dir build/Web

Use the run ID of a successful Build Unity Web preview run (the number in the run's address on GitHub).
